Services

BIM Modeling & Coordination

Architectural, structural and MEP models in Revit, plus parametric family creation. Multidisciplinary model coordination, clash detection and issue tracking in Navisworks, and information management aligned with ISO 19650 (BEP, MIDP, LOD/LOI).

Civil 3D, Scan-to-BIM & Drawings

Civil 3D models for roads, drainage and hydraulic works. Point-cloud processing in ReCap and WebODM to build as-built Revit and Civil 3D models. Complete construction drawing sets in AutoCAD and Civil 3D, plus GIS data in ArcGIS and QGIS.

Automation & BIM Development

Custom C#/.NET plugins for AutoCAD, Civil 3D, Revit and Navisworks; Python (pyAutoCAD, pyRevit) and Dynamo scripts that cut drafting and QA/QC time. IFC tooling, BIM-GIS integration and Power BI dashboards for project reporting.

Open-Source Tools

Code I write to automate BIM and CAD workflows — available on GitHub

GenLay

C# · .NET · AutoCAD API

AutoCAD plugin that creates a numbered sheet for every frame drawn in model space — it clones a base layout and centers the viewport at the chosen scale, replacing hours of manual sheet setup.

View repository

BlockAlignTool

C# · .NET · AutoCAD API

AutoCAD plugin that aligns existing blocks to a polyline or inserts them at regular intervals along it, rotated to the tangent — for poles, lights, signs and chainage marks.

View repository

IFC Auditor

Python · IFC

Checks IFC models for missing properties and data quality issues before delivery.

View repository

Dynamo Scripts

Dynamo · Python · Civil 3D / Revit

Dynamo graphs for Civil 3D and Revit that automate modeling and documentation tasks.

About

Andrés G. Rodríguez

BIM Specialist | BIM Coordination | BIM Developer

I'm a BIM Specialist and BIM Developer based in Bogotá, Colombia, with more than 10 years in the AEC industry. I started as a CAD drafter and grew into BIM coordination on large public infrastructure — metro, rail, hydroelectric, highway and airport projects — working with multidisciplinary teams in Colombia and across Latin America.

What sets my work apart is that I combine production with development: besides modeling in Revit and Civil 3D, coordinating in Navisworks and turning point clouds into BIM models, I write my own C#, Python and Dynamo tools to remove repetitive work and raise quality. I'm also studying a Bachelor's in Architecture. I work in Spanish and English and I'm comfortable collaborating remotely with international teams.
